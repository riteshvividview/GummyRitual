How to work: edit, don't regenerate

Every replacement starts from the existing image or frame, with the new pack mockup attached. Ask the tool to swap only the pouch. The background, light, gummies and fruit stay as they are, so the result still matches the rest of the page.

All references are already collected for you in Organize-kids-section/refs/. File names in the "Attach" lines below refer to that folder.

For the videos, first make the start frame and the end frame as image edits, then generate the video from those two frames (first-frame and last-frame mode in Veo, Kling or Runway). That's the only reliable way to keep the label sharp and the scene identical.
